# Algoritmos e Programação I

Repositório com exercícios em Java feitos durante as aulas da disciplina de Algoritmos e Programação I.

## Organização

- `Aula for`: exercícios trabalhados com laços `for`.
- `Aula4` e `aula5`: atividades das aulas correspondentes.
- `exercicios while`: exercícios com laços `while`.
- `laço for`: atividades de repetição com `for`.
- Na raiz: exercícios numerados e o arquivo `jogo.java`.

Cada arquivo pode ser aberto e executado separadamente. Para compilar e executar um exercício, use o nome da classe correspondente, por exemplo:

```bash
javac exercicio1.java
java exercicio1
```
